# JWT-startprojekt

Spring Boot-backend til JWT-dagen i Technology 2. Projektet vokser trin for trin: opgaven siger, når I skal hente flere filer.

1. Åbn mappen i IntelliJ, og start `JwtApplication` med ▶.
2. Tjek at `http://localhost:8080/hello` svarer.
3. Start en tunnel i en terminal: `cloudflared tunnel --url http://localhost:8080`
   - Mac: `brew install cloudflared`
   - Windows: `winget install --id Cloudflare.cloudflared`
